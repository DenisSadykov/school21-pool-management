# Личный кабинет

Раздел `/profile` теперь содержит Обзор, Личные данные и Безопасность.
`GET /api/me/statistics` возвращает только историю текущего пользователя. Параметры
`user_id` и `pool_id` не переключают владельца или область доступа. Вход и обязательная
смена пароля проверяются существующими middleware; ответ не кешируется.

## Что считаем

- Все сохранённые привязки к бассейнам (включая завершённые и архивные), а также
  собственные смены, проверки и начисления с привязкой к бассейну.
- Прошедшая смена: время окончания уже наступило по Москве. Текущая смена показывается
  вместе с будущими. Часы — длительность записи в расписании, не подтверждённый выход.
- График: последние 12 календарных месяцев, только прошедшие записи, нулевые месяцы
  сохранены. Точные числа также доступны текстом.
- Коины: те же ставки и правила, что в «Волонтёрах»: все записи на смены, включая
  будущие; групповые; исповедь; роль тимлида; мероприятия; ручные награды и корректировки.
  Это расчёт, не подтверждение выплаты. Глобальные старые награды без pool_id показаны
  отдельно и не смешиваются с общей суммой. Глобальные поля исповеди/корректировок не
  приписываются произвольному бассейну.
- Встречи мастера: все встречи его трайба для коинов, только предыдущие даты для истории.
  Помощник: только предыдущие даты с assistant_attending=true, как в существующем расчёте.
  Сегодняшние встречи станут прошедшими завтра. Ручной override меняет коины, но не статистику встреч.
- Ачивки временно убраны для всех пользователей по запросу владельца. API оставляет
  поле `achievements: []` для совместимости. Секция и расчёт достижений отсутствуют;
  историю участия и коины это не меняет. Старую реализацию можно восстановить из Git.

## Ограничения истории

Отдельного подтверждения посещаемости и исторических тарифов пока нет. После удаления
смен/бассейнов, смены роли или трайба, редактирования мероприятий, количества проверок
либо тарифов расчёты могут измениться. Роль берётся из сохранённой привязки к конкретному
бассейну, а не текущей глобальной роли. Старая информация, которая уже удалена, не
восстанавливается и не выдумывается. Бассейн без активности всё равно виден в истории.

Реализация не добавляет таблиц и миграций; использует пакетное чтение собственных
данных, без запросов на каждый бассейн. Настройки профиля и пароля остаются доступны
при ошибке загрузки статистики. Открытие обзора заново обновляет данные.
