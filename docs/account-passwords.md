# Вход и пароли

Вход требует пароль для любой роли. Для волонтёров, трайб-мастеров и помощников
без ранее установленного пароля начальный пароль совпадает с сохранённым ником
(с учётом регистра). После входа обязательно установить личный пароль:
8–256 символов, не совпадающий с ником и текущим паролем.

До смены доступны только просмотр своей сессии и смена пароля.
Другие защищённые запросы сервер отклоняет независимо от интерфейса.
В дальнейшем пароль можно менять в «Личных данных».

Существующие пароли, в том числе админов и тимлидов, не сбрасываются.
Новые личные пароли хранятся только в виде хеша. Изменение пароля завершает
старые сеансы; сменивший пароль получает новую сессию. Публикация этого
обновления требует повторного входа для всех старых сессий.

Начальный пароль-ник не подтверждает личность: любой знающий ник может занять
аккаунт до владельца. Это согласованный владельцем платформы временный способ
первого входа, а не безопасная проверка через Telegram. Не отправляйте личные
пароли в рассылках. При подозрении на перехват администратору нужно проверить
личность владельца перед восстановлением доступа.

Миграция схемы базы не требуется. Настройки Telegram и рассылки не меняются,
автоматические сообщения о смене входа не отправляются.
