# Личные заметки о пирах

Раздел `/my-notes` доступен каждому вошедшему пользователю после смены начального пароля.
Из «Пиров» ссылка у ника открывает собственную историю по этому ученику и новую запись.
Общий список собирает заметки автора за всё время, без фильтра по бассейну.
Есть поиск по нику, сортировка по дате создания, страницы по 50 записей, изменение и удаление с подтверждением.

Сервер всегда ограничивает выборку, изменение и удаление `author_id` текущей сессии.
Никакая роль, включая администратора, не получает обход этого ограничения.
Создание разрешено только для пира активного бассейна, доступного автору.
Чтение и изменение своих исторических записей не требуют активного бассейна.
Отдельного публичного GET по ID нет. Чужая запись при PATCH/DELETE возвращает 404.
Переданный клиентом author_id игнорируется, автор берётся только из сессии.

Текст: 1–4000 символов после обрезки краевых пробелов. HTML показывается обычным текстом.
Дата хранится в UTC, показывается по Москве. PATCH требует исходный updated_at, чтобы не затереть изменение из другой вкладки.
При удалении пира/бассейна связь обнуляется, ник и заметка автора остаются; при удалении автора удаляются его заметки.
Заметки не влияют на штрафы, баллы, коины, рассылки и не входят в обычные выгрузки учеников.
Приватность реализована на уровне приложения: это не сквозное шифрование от администраторов базы и резервных копий.

## Обновление ВМ

Перед публикацией сделать и проверить полный backup, затем явно применить
`backend/migrations/20261011_student_notes.sql` к рабочей базе через внутренний контейнер Postgres.
Миграция добавляет одну таблицу с FK и индексами; существующие записи не меняются.
Не включать AUTO_INIT_DB/RUN_SCHEMA_MIGRATIONS. Read-only deploy smoke проверит наличие таблицы перед переключением версии.
При откате приложения таблицу не удалять: она совместима со старой версией и сохраняет новые записи.

## Direction contract

THESIS: личная история наблюдений, без рейтинга учеников и административного обзора.
OWN-WORLD: существующие тема, типографика, синие акценты, lucide-иконки и стандартные кнопки платформы.
STORY: выбрать пира, сохранить собственную запись, найти и исправить её позже.
FIRST VIEWPORT: заголовок и пояснение приватности; создание сверху, затем поиск и порядок, плоский список записей.
FORM: точное расширение существующего интерфейса, без нового визуального мира и без concept seed.
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.
