# Personal achievements — local extension

Mode: Operate with an image-led personal collection. Extend the established personal cabinet; no platform redesign or award editor. Approved user plan: manually issued images only, both themes, full title/date, full-image viewer, empty/loading/error states. Creation and granting happen through the chat, admin only.

## Direction contract

THESIS: a quiet collection of real received artwork, never a progress or locked-rewards dashboard. No automatic achievements.

OWN-WORLD: inherit the cabinet's system font, theme surfaces, blue actions, thin borders and 12px panels. The awarded artwork retains its own palette and transparency.

STORY: open the Achievements tab, recognize the received image and Moscow award date, open the full image, return to the same place. No issuing controls.

FIRST VIEWPORT: the existing cabinet heading and tabs stay fixed in the hierarchy. A collection heading and received count introduce a responsive image grid. Each image fits completely above a wrapping title and date; on mobile one comfortable column. The empty collection is one plain message, not locked placeholders.

FORM: local extension of the approved existing surface; no concept seed or new identity required. Signature interaction: open the complete image in a native, keyboard-accessible dialog and return focus on closing. No decorative motion.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

Asset provenance: first production award uses the user-approved generated PNG exec-44a8963a-e960-4ebf-8099-ecb6ab901aec.png unchanged. No generated image is bundled with the interface; uploaded awards are private database content. Visual verification uses a labeled local fixture, never a real production award.
